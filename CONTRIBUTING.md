# Contributing to KidneyOS

See the [book](docs/building.md) for how to set up a build environment. Once
you have one, `make help` lists everything the Makefile can do.

## Before you start: install the git hooks

```sh
make hooks
```

This points Git at the hooks in [`.githooks`](.githooks) (it sets
`core.hooksPath`):

- **pre-commit** refuses uncompressed disk images and files over 1 MiB, then
  runs `make check-fast`.
- **commit-msg** checks the commit message format described below.

If you really need to, `git commit --no-verify` skips both.

## Checks

| Command           | What it runs                                                                   |
| ----------------- | ------------------------------------------------------------------------------ |
| `make check-fast` | `cargo fmt --check` (kernel and programs workspaces), shellcheck, mdsh, actionlint |
| `make check`      | `check-fast`, plus building the user programs, clippy with `-D warnings` (both workspaces), the tests, and the ISO |

CI runs the same targets, so `make check` passing locally means CI should
pass too. Use `make fmt` to fix formatting. Checks whose tool isn't installed
(shellcheck, mdsh, actionlint) are skipped with a warning locally, but fail in
CI; the Nix devShell has all of them.

Before sending changes that affect booting, also run `make run-qemu-ng` (or
`make smoke-test`, which waits for the `kidney:/$` prompt without a terminal).

## Commit messages

Every commit message is a single [Conventional Commits](https://www.conventionalcommits.org/)
subject line, and nothing else:

```text
fix(make): always rebuild user programs
```

- The type is one of `build`, `chore`, `ci`, `docs`, `feat`, `fix`, `perf`,
  `refactor`, `revert`, `style` or `test`, optionally followed by a lowercase
  scope in parentheses and a `!` for breaking changes.
- At most 72 characters, no trailing period.
- **No body and no trailers**: no `Signed-off-by`, `Co-Authored-By` or similar
  lines. If a change needs explaining, put the explanation in a code comment,
  the docs, or the pull request description.

Merge, revert and `fixup!`/`squash!` messages generated by Git are let through
by the hook.

Keep each commit to one logical change, so that the subject line can describe
all of it.

## Layout

- `kernel/`, `shared/`, `trampoline/`, `syscalls/`: the kernel's cargo
  workspace (root `Cargo.toml`), built for `build-support/i686-unknown-kernel.json`.
- `programs/`: user programs. The Rust ones are a separate cargo workspace
  (`programs/Cargo.toml`) built for `i586-unknown-linux-gnu`; the C and
  assembly ones are built by `programs.mk`. Everything ends up in
  `build/programs/`.
- `build/`: all build outputs, including `build/disk.img`, the disk QEMU and
  Bochs use. It is unpacked from `build-support/disk.img.gz`; run
  `make reset-disk` to undo changes KidneyOS made to it.
